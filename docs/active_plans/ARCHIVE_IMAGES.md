1. Copy every image attachment from every direct Archive Shows text channel, paginating
   to an empty page. Keep unchanged CDN response bytes outside the repository and deployment.
2. Organize by channel/show, retain message and attachment IDs and hashes, and generate
   contact sheets before selecting website photographs.
3. Assess actual images and show context. Reject unrelated images, planning diagrams,
   other clubs, WIP, promotional overlays, and visitor-focused photographs.
4. Publish a small, attributed selection in shared D revisions only: a real castle-category
   image, recent railway detail, and a streetscape. Keep copy editable in Markdown and the
   manifest; preserve restrained alpha, balanced beta, and playful gamma treatments.
5. Run all strict builds and browser journeys, check selected images at mobile and desktop
   widths, validate provenance/derivatives, and confirm original A/B/C/D remain unchanged.
