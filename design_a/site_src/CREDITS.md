## Approved identity

The browser icon is a proportionally resized copy of the supplied circular NILBC logo.
The NILBC banner and Matchstick model rendering were supplied by the club owner. Artist
attribution and an exact parts list were not supplied. Originals remain preserved in the
source repository. The website derivative removes stray slide text and the bottom border;
the mascot image is a rendering, not a physical-model photograph.

---

## Design and software


The layout and stylesheet were created for this demo. The site uses MkDocs Material with
local images, system typography, and native HTML navigation. It has no analytics, external font
requests, application form, or backend. Repository licenses do not override third-party asset rights.
